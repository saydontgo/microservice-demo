# 前端状态与交互设计

## 1. 登录态

登录成功后前端保存：

```json
{
  "token": "...",
  "role": "BUYER",
  "expiresAt": 1770000000
}
```

保存位置可使用 `localStorage`。退出登录时清除本地登录态并调用后端退出接口。

## 2. 主题状态

卖家支持主题切换：

| 主题 | 样式 |
| --- | --- |
| `LIGHT` | 白色背景、深色文字 |
| `DARK` | 深色背景、浅色文字 |

主题保存在卖家资料中，登录后从资料接口加载。

## 3. 表格状态

每个表格维护：

- 当前筛选条件。
- 当前页码。
- 每页数量。
- 加载中状态。
- 空状态。
- 错误状态。

## 4. 复制交互

商品名、商品 ID、订单 ID 支持复制。复制成功后给出轻提示：

```text
已复制
```

复制失败时提示：

```text
复制失败，请手动复制
```

## 5. 表单提交

- 提交前做基础校验。
- 提交中禁用按钮。
- 成功后刷新对应数据。
- 失败时展示后端错误信息。

## 6. 幂等键生成

前端每次写请求生成 UUID 作为 `Idempotency-Key`。同一次按钮提交重试时复用同一个 Key，用户重新发起新操作时生成新 Key。
