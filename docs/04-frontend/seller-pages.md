# 卖家页面设计

## 1. 商品管理 Tab

### 顶部趋势图

默认展示近 7 天：

- 成交金额变化。
- 退款金额变化。
- 退款率变化。

卖家可设置连续天数或选择连续日期区间。

### 筛选区

| 筛选项 | 说明 |
| --- | --- |
| 时间 | 默认近 7 天 |
| 商品状态 | 在售、正在下架、已下架、预售中 |
| 商品 ID | 精确查询 |
| 商品名 | 前缀匹配 |
| 是否发货 | 勾选框 |

### 表格列

| 列 | 说明 |
| --- | --- |
| 商品名 | 显示在最前面，可复制 |
| 商品 ID | 商品名下方展示，可复制 |
| 状态 | 商品当前状态 |
| 成交金额 | 查询时间范围内成交金额 |
| 退款金额 | 查询时间范围内退款金额 |
| 退款率 | 退款金额 / 成交金额 |
| 库存量 | 预售中展示 0 |
| 操作 | 补库存、一键发货、下架 |

### 操作展示规则

- `1`（在售）：显示下架按钮；有订单时显示一键发货。
- `2`（预售中）：库存展示 0，显示补库存按钮；有订单时可一键发货。
- `3`（正在下架）：买家不可见，卖家可补库存和一键发货。
- `4`（已下架）：只允许补库存或重新上架，具体可后续扩展。

## 2. 设置 Tab

展示和编辑：

- 注册人。
- 店铺名字。
- 店铺头像。
- 成交商品总额。
- 主题样式。

操作：

- 保存资料。
- 切换明亮/黑暗主题。
- 退出登录。
