# 买家页面设计

## 1. 商品浏览 Tab

### 筛选区

- 商品名前缀输入框。
- 搜索按钮。
- 重置按钮。

### 表格列

| 列 | 说明 |
| --- | --- |
| 商品名 | 展示商品名称 |
| 商品 ID | 可复制 |
| 店铺名 | 卖家店铺 |
| 单价 | 元格式展示 |
| 状态 | 在售或预售中 |
| 库存 | 预售中展示 0 |
| 购买数量 | 输入框，最大 100 |
| 操作 | 下单并支付 |

### 下单校验

- 购买数量必须大于 0。
- 购买数量不超过 100。
- 总金额不超过 1 亿。
- 余额不足时提示充值。

## 2. 订单管理 Tab

默认展示：

- `1`（已下单未发货）
- `2`（配送中）

### 表格列

| 列 | 说明 |
| --- | --- |
| 订单 ID | 可复制 |
| 商品名 | 下单快照 |
| 商品 ID | 可复制 |
| 数量 | 购买数量 |
| 金额 | 订单金额 |
| 状态 | 订单状态 |
| 创建时间 | 下单时间 |
| 操作 | 退款或确认收货 |

### 操作规则

- `1`（已下单未发货）：展示退款按钮。
- `2`（配送中）：展示确认收货按钮。
- `3`（已收货）：只展示状态。
- `4`（已退款）：只展示状态。

## 3. 设置 Tab

展示和编辑：

- 买家昵称。
- 买家头像。
- 买家手机号。
- 买家收货地址。
- 当前余额。

操作：

- 保存资料。
- 充值。
- 退出登录。
