# 测试策略

## 1. 测试目标

确保核心交易链路、鉴权、幂等、状态流转和数据统计符合 PRD。

## 2. 单元测试重点

| 模块 | 测试点 |
| --- | --- |
| Auth | 密码校验、角色匹配、Token 过期 |
| Product | 状态流转、前缀搜索参数、买家可见性 |
| Inventory | 补库存、库存不足、预售展示为 0 |
| Order | 下单、退款、发货、确认收货状态机 |
| Payment | 充值、扣款、退款、余额不足 |
| Analytics | 退款率、空日期补 0、趋势区间连续 |

## 3. 集成测试场景

### 买家主链路

1. 注册买家。
2. 充值。
3. 搜索商品。
4. 下单支付。
5. 查看未发货订单。
6. 退款。
7. 校验余额恢复。

### 卖家主链路

1. 注册卖家。
2. 创建商品。
3. 买家下单。
4. 卖家查看商品管理列表。
5. 卖家一键发货。
6. 买家确认收货。
7. 卖家下架商品。

## 4. 幂等测试

- 同一 `Idempotency-Key` 重复下单只生成一个订单。
- 同一 `Idempotency-Key` 重复退款只返还一次余额。
- 同一 `Idempotency-Key` 重复发货只更新一次订单状态。
- 同一 Key 携带不同请求体返回 `IDEMPOTENCY_CONFLICT`。

## 5. 边界测试

- 购买数量等于 100 成功，超过 100 失败。
- 总金额等于 1 亿成功，超过 1 亿失败。
- 余额刚好等于订单金额成功。
- 库存刚好等于待发货数量成功。
- 下架中商品买家不可见。
- 有未完成订单的商品不能转为已下架。
