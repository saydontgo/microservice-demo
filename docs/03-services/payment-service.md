# Payment Service 设计

## 1. 职责

- 买家余额充值。
- 下单支付扣款。
- 退款入账。
- 支付流水记录。

## 2. 金额约定

- 金额统一使用分。
- 使用 `BIGINT` 存储。
- 前端展示时转换为元。

## 3. 充值流程

1. 校验充值金额大于 0。
2. 校验幂等键。
3. 锁定买家资料行。
4. 增加 `balance_cent`。
5. 写入 `payment_transactions`，类型为 `1`（充值）。
6. 返回最新余额。

## 4. 支付流程

支付由 Order Service 编排，Payment Service 提供扣款能力：

1. 锁定买家资料行。
2. 校验余额足够。
3. 扣减余额。
4. 写入支付流水，类型为 `2`（支付扣款）。

## 5. 退款流程

退款由 Order Service 编排，Payment Service 提供入账能力：

1. 锁定买家资料行。
2. 增加余额。
3. 写入退款流水，类型为 `3`（退款入账）。

## 6. 风险点

- 余额不能由前端直接更新。
- 重复请求必须通过幂等键防止重复充值、扣款或退款。
- 支付流水与余额更新必须在同一事务中完成。
