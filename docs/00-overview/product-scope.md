# 产品范围说明

## 1. 产品定位

本 Demo 用于演示一个小型电商系统的端到端业务闭环，重点体现买家、卖家、商品、订单、支付、库存和统计分析之间的协作关系。

## 2. 用户角色

| 角色 | 入口 | 能力 |
| --- | --- | --- |
| 买家 | 登录页选择买家身份 | 浏览商品、下单支付、查看订单、确认收货、退款、维护资料、充值 |
| 卖家 | 登录页选择卖家身份 | 维护店铺资料、管理商品、补库存、下架商品、一键发货、查看经营趋势 |

## 3. 业务范围

### 买家侧

- 注册和登录。
- 商品名前缀搜索。
- 下单并支付。
- 全局购买上限：单次购买数量不超过 100，总金额不超过 100,000,000。
- 维护买家昵称、头像、手机号、收货地址。
- 查看余额并充值。
- 查询订单，默认展示已下单未发货和配送中。
- 对配送中订单确认收货。
- 对未发货订单申请退款。

### 卖家侧

- 注册和登录。
- 维护注册人、店铺名称、店铺头像、主题样式。
- 查看成交商品总额。
- 按时间、商品状态、商品 ID、商品名前缀、是否发货筛选商品。
- 查看商品成交金额、退款金额、退款率、库存量。
- 商品名和商品 ID 支持复制。
- 对在售商品发起下架。
- 对预售和下架中商品补库存。
- 对有订单的商品一键发货。
- 查看连续天数内成交金额、退款金额、退款率趋势。

## 4. 非目标

- 不做真实支付渠道对接。
- 不做物流三方接口对接。
- 不做复杂促销、优惠券、会员体系。
- 不做多租户隔离、跨机房容灾和生产级高可用。
- 不做真实图片存储服务，头像可先保存 URL。
- 不做搜索引擎，商品名仅使用 MySQL 前缀匹配或缓存优化。

## 5. 成功标准

- 能完整跑通买家注册、充值、下单、退款、确认收货流程。
- 能完整跑通卖家注册、维护商品、补库存、发货、下架流程。
- 文档中明确服务边界、表字段、缓存 Key、核心 SQL 和接口契约。
- 架构适合后续逐步生成代码，但当前阶段不写业务代码。
