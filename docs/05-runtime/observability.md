# 可观测性设计

## 1. 日志

后端应输出结构化日志，字段包括：

| 字段 | 说明 |
| --- | --- |
| `request_id` | 请求 ID |
| `user_id` | 当前用户 |
| `role` | 当前身份 |
| `path` | 请求路径 |
| `method` | HTTP 方法 |
| `status_code` | 响应状态码 |
| `latency_ms` | 耗时 |
| `error_code` | 业务错误码 |

## 2. 指标

建议记录：

- 登录成功/失败次数。
- 下单成功/失败次数。
- 退款成功/失败次数。
- 发货成功/失败次数。
- 库存不足次数。
- 接口耗时。

## 3. Trace

Demo 阶段可通过 `request_id` 串联日志，不强制接入分布式追踪。

## 4. 告警建议

本地 Demo 不强制做告警，但可在日志中明显标识：

- 重复幂等请求。
- 余额不足。
- 库存不足。
- 非法状态流转。
- 鉴权失败。
